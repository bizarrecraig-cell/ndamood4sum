# ndamood4sum | Adult Entertainment Reviews, Videos & Stories

A complete static website for adult entertainment reviews, curated video highlights, and original erotic short stories.

## Features

- **Age gate** on the homepage (session-based)
- Responsive dark theme
- **Reviews** page with category filters (Straight / Gay / Cams / Indie)
- **Videos** page with curated highlight cards
- **Stories** page with expandable full short fiction
- **About** page
- Mobile-friendly navigation
- Clean, modern UI

## How to run

This is a pure static site. No build step required.

### Option 1 – Open locally
Simply open `index.html` in any modern browser.

### Option 2 – Local server (recommended)
From this folder run:

```bash
# Python
python3 -m http.server 8080

# or Node
npx serve .
```

Then visit `http://localhost:8080`

### Option 3 – Deploy
Upload the entire folder to any static host:
- Netlify
- Vercel
- GitHub Pages
- Cloudflare Pages
- Any web host that supports static HTML
